| **`HRH-03`** | Recruiter or hiring manager cannot approve HR handover (`403 Forbidden`) | `OfferAndHrHandoverService::approveForHandover()` | `HrHandoverSafetyGateTest.php` lines 139–149 |

| **`HRH-05`** | Duplicate handover dispatch with same idempotency key produces one outbound create call and returns existing result | `OfferAndHrHandoverService::dispatchHandover()` | `HrHandoverSafetyGateTest.php` lines 253–266 |
| **`HRH-06`** | Ambiguous timeout triggers reconciliation check before retry (`409 HR_HANDOVER_RECONCILIATION_REQUIRED`) | `OfferAndHrHandoverService::dispatchHandover()` & `reconcileHandover()` | `HrHandoverSafetyGateTest.php` lines 206–234 |

| **`HRH-08`** | All validation, approval, dispatch, retry, failure, and reconciliation actions create `AuditEvent` records | `OfferAndHrHandoverService` & `AuditService::record()` | `HrHandoverSafetyGateTest.php` lines 268–288 |
